# 화면 명세서

> 리디자인 전 참고용. **각 화면이 무엇을 해야 하는가**와 **어떤 상태가 있는가**를 정리했습니다.
> 데이터 제약은 [DATA.md](DATA.md), 색·타이포는 [DESIGN-TOKENS.md](DESIGN-TOKENS.md) 참고.
> 실제 화면은 `figma-export/` 의 HTML 21개.

---

## 화면 지도

```
[로그인 /] ──가입──> [회원가입] ──자동로그인──> [온보딩] ──> [지도 /map]
                                                              │
   ┌──────────────────────────────────────────────────────────┤
   │                                                          │
[AI 상담 /chat]                                    [지역 패널] ─> [지역 상세 /region]
   │  추천 버튼                                                     │
   └──────────────> 지역/코스 상세로 이동                            │
                                                    [코스 만들기 /course]
                                                              │ 저장
                                                    [저장 완료 /course/saved]
                                                              │ 후기 쓰기
[내 코스 /my/courses] <──────────────────> [후기 작성 /review/new]
                                                              │
                                          [후기 상세 /review/{id}] ──공유──>
                                                              │
                                              [후기 피드 /reviews] ──> 지역 상세 (탐색 루프)
[프로필 /profile]
```

---

## 화면별 명세

### 1. 로그인 `/` — `01`, `02`
| | |
|---|---|
| 목적 | 진입 및 인증 |
| 로그인 필요 | ❌ (로그인 상태로 오면 `/map` 으로 보냄) |
| 데이터 | 없음 |
| 액션 | 로그인 / 회원가입 이동 / 소셜 로그인(**미구현 · 자리만 있음**) |
| **상태** | 기본 · **오류**(이메일·비밀번호 불일치) · 로그아웃 직후 안내 |

> 카카오·구글 버튼은 **동작하지 않습니다.** 추후 확장 자리입니다.

### 2. 회원가입 `/signup` — `03`
| | |
|---|---|
| 입력 | 이메일 · 비밀번호(8자↑) · 비밀번호 확인 · 닉네임(30자↓) |
| **상태** | 기본 · 오류(짧은 비번 / 불일치 / 중복 이메일) — **입력값 유지됨** |
| 이후 | 가입 즉시 자동 로그인 → 온보딩 |

### 3. 온보딩 `/onboarding` — `04`, `05`
| | |
|---|---|
| 목적 | 취향 2문항 수집 (여행지 유형 / 분위기) |
| **상태** | 1단계 · 2단계 · 선택 전(다음 버튼 비활성) |
| 특이 | **건너뛰기 가능.** 현재 응답은 추천에 반영되지 않음(수집만) |

### 4. 지도 `/map` — `06`(비로그인), `09`, `10`(AI 모달)
| | |
|---|---|
| 목적 | **서비스의 중심 화면.** 250개 시군구를 랭킹 없이 탐색 |
| 로그인 필요 | ❌ |
| 데이터 | 시군구 폴리곤(TopoJSON) · 오늘의 숨은 여행지 카드 |
| 액션 | 지역 클릭 → 우측 패널 / 검색 / **무작위(룰렛 3~4초)** / AI 추천 모달 |
| **상태** | 지도 로딩 · 미선택 · 선택됨(패널 열림, 카드 숨김) · 룰렛 진행 중 |

> ⚠ **지도 SVG와 우측 패널 내용은 JS가 그립니다.** export HTML에는 비어 있습니다.
> 왼쪽 카드는 `xl` 이상에서만 보입니다(좁은 화면에선 지도를 가림).

### 5. 지역 패널 `/region/panel` — `11`
지도 우측에 슬라이드로 뜨는 요약. **독립 페이지로도 열려 export에 실데이터가 담깁니다.**
특산물 · 착한가격업소 · 추천 반일 코스 · 상세로 이동.

### 6. 지역 상세 `/region?sigCd=` — `12`
| | |
|---|---|
| 구성 | 지역명 · 지표 4종 · **이 지역은 이런 곳이에요** · 추천 코스 · 착한가격업소 표 |
| **상태** | 특산물 없는 지역 → **"유명한 것들" 섹션 통째로 사라짐** (250곳 중 226곳) |
| | 랜드마크 설명 → **나중에 채워짐** (로딩 → 내용 / 없으면 줄 삭제) |
| 액션 | 길찾기(카카오맵) · 코스 담기 |

### 7. 코스 만들기 `/course?sigCd=` — `07`(비로그인), `13`(빈), `14`(담긴)
| | |
|---|---|
| 목적 | 왼쪽 후보에서 담아 오른쪽 타임라인 구성 |
| 로그인 필요 | ❌ 둘러보기 / ✅ **저장할 때만** |
| 구성 | 좌: 탭 4종(관광지·먹거리·착한식당·특산물) · 우: **동선 지도 + 타임라인** |
| 액션 | 담기 / 삭제 / **드래그로 순서 변경** / 자세히 펼치기 / 저장 |
| **상태** | 비로그인(저장→"로그인하고 저장") · 빈 코스(저장 버튼 비활성) · 담긴 상태 |

> ⚠ 담기·타임라인·지도는 **전부 JS**입니다. export에는 후보 목록과 초기 경유지만 있습니다.
> 비로그인으로 담은 코스는 sessionStorage에 보관돼 **로그인 후 복원**됩니다.

### 8. 저장 완료 `/course/saved?courseId=` — `16`
| | |
|---|---|
| 구성 | 코스명 · 총 장소 · **소요시간 · 이동거리** · 경유지 칩 · **동선 지도** |
| **상태** | 경로 계산 전("계산 중…") → 계산 후(5.6km / 15분) · 키 없음 안내 |
| 액션 | **후기 쓰기**(주요) / 내 코스 / 지도로 |

> 소요시간·거리는 **저장 후에만** 나옵니다. 편집 중에는 계산하지 않습니다.

### 9. 내 코스 `/my/courses` — `15`, `21`(빈 상태)
| | |
|---|---|
| 로그인 필요 | ✅ |
| 카드 구성 | 지역 · 코스명 · 저장일 · 경유지 칩 · 총 장소/착한가격 수 |
| 액션 | 후기 유무에 따라 **"후기 쓰기" ↔ "후기 보기"** 전환 / 지역 다시 보기 |
| **상태** | 코스 있음 · **빈 상태(신규 사용자의 기본)** |

### 10. 후기 작성 `/review/new?courseId=` — `18`
| | |
|---|---|
| 구성 | 대상 코스 요약 · **1 사진 · 2 후기 · 3 공개설정** 3단계 · 하단 고정 저장바 |
| 제약 | 사진 최대 5장 · 장당 10MB · jpg/png/gif/webp |
| **상태** | 신규 작성 · **수정 모드**(기존 내용·사진 표시) · 업로드 미리보기 |

### 11. 후기 상세 `/review/{id}` — `17`
| | |
|---|---|
| 목적 | **공유 링크가 가리키는 페이지** |
| 로그인 필요 | ❌ 공개 후기 / ✅ 비공개는 작성자만 |
| 액션 | **링크 복사해 공유** / 후기 수정(본인) / 이 지역 보기 / **코스 만들기(탐색 루프)** |
| **상태** | 사진 있음/없음 · 본인/타인 · 비공개 배지 |

### 12. 후기 피드 `/reviews` — `08`
| | |
|---|---|
| 로그인 필요 | ❌ |
| 구성 | 공개 후기 카드 그리드(대표 사진·지역·코스명·요약·작성자) |
| **상태** | **빈 상태가 현재 기본** (§DATA 5 참고) · 사진 없는 후기 · 사진 여러 장 배지 |

### 13. 프로필 `/profile` — `19`
| | |
|---|---|
| 로그인 필요 | ✅ |
| 구성 | 아바타(사진 or 이니셜) · 닉네임 · 이메일 · 소개 · **활동 지표 2종** · 수정 폼 · 비밀번호 변경 · 로그아웃 |
| **상태** | 사진 있음/없음 · 저장 성공 · 오류 |

### 14. AI 상담 `/chat` — `20`
| | |
|---|---|
| 로그인 필요 | ❌ |
| 구성 | 말풍선 대화 · 예시 질문 칩 · 하단 고정 입력창 |
| 액션 | 질문 → 답변 + **지역/코스 이동 버튼** |
| **상태** | 첫 진입(예시 질문) · 대기("추천을 찾고 있어요…") · 답변 · 오류 · **키 미설정 안내** |

> ⚠ 대화 내용은 **전부 JS**입니다. export에는 첫 진입 화면만 있습니다.
> 대화는 저장되지 않아 **새로고침하면 초기화**됩니다.

## 리디자인 시 꼭 지켜야 할 것

1. **빈 상태를 먼저 그려주세요.** 후기·내 코스는 빈 상태가 첫인상입니다.
2. **비동기로 채워지는 자리**를 로딩 상태와 함께 설계해주세요 (랜드마크 설명, 코스 경로, AI 답변).
3. **로그인/비로그인 두 벌**이 필요합니다 — 헤더와 코스 저장 버튼이 달라집니다.
4. **디자인 토큰 이름은 유지**해주세요. 값은 자유롭게 바꾸셔도 됩니다 → [DESIGN-TOKENS.md](DESIGN-TOKENS.md)
5. 데이터로 만들 수 없는 UI(평점·인기순·혼잡도)는 피해주세요 → [DATA.md](DATA.md) §8
