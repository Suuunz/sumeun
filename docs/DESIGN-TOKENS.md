# 디자인 토큰

> **값은 자유롭게 바꿔주세요. 다만 토큰 이름은 유지해주세요.**
> 이름만 유지되면 구현은 CSS 변수 하나 교체로 끝납니다.
> 이름 체계가 바뀌면 화면 전체를 손봐야 합니다.
>
> 원본: `src/main/resources/static/css/tokens.css`

---

## 왜 이름이 중요한가

화면의 모든 색·글자·간격은 CSS 변수를 참조하고, Tailwind 설정이 그 변수를 다시 참조합니다.

```
tokens.css ──> :root { --accent: #D08A5D }
                     ↓
layout.html ──> tailwind.config { colors: { primary: "var(--accent)" } }
                     ↓
화면 ─────────> class="bg-primary"
```

`--accent` 값을 바꾸면 **버튼·링크·지도 선·로고까지 한 번에** 바뀝니다.
반대로 `--accent`를 없애고 `--brand-orange` 같은 새 이름을 만들면 참조가 전부 깨집니다.

## Figma 로 옮기기

1. **Local variables** 컬렉션을 `color` / `typography` / `spacing` / `radius` 로 나눕니다.
2. 위 표의 **토큰 이름을 변수명 그대로** 씁니다 (`accent`, `surface-alt`, `fs-card` …).
3. 값만 새 컨셉으로 교체합니다.
4. 컴포넌트는 위 목록 기준으로 만들어주세요.

이렇게 넘겨주시면 구현은 `tokens.css` 값 교체 + 컴포넌트 스타일 조정으로 끝납니다.

## 바꾸기 전에 알아두면 좋은 것

- **`--accent` 하나가 매우 넓게 쓰입니다** — 버튼, 링크, 지도 동선, 선택된 시군구, 로고 발자국 한쪽, 룰렛 하이라이트. 채도가 너무 높으면 지도에서 눈이 아픕니다.
- **`--surface-alt` 와 `--bg` 의 차이가 작습니다** (`#F4F1EB` vs `#FAF8F4`). 의도적으로 은은하게 잡았지만, 대비를 키우면 입력창·썸네일 자리가 더 또렷해집니다.
- **지도 색(`--map-land`, `--map-stroke`)은 따로 뺐습니다.** UI 테두리(`--border`)를 진하게 만들면 카드까지 두꺼워져서, 지도만 별도 토큰으로 분리했습니다.
- **다크 모드는 아직 없습니다.** `:root` 에만 정의되어 있고 `html.light` 클래스만 붙어 있습니다. 다크를 넣으려면 같은 이름으로 다크 값 세트를 하나 더 만들어주세요.
