# 데이터 현황과 제약

> 디자인 전에 반드시 읽어주세요.
> **없는 데이터를 전제로 한 디자인은 구현 단계에서 되돌아옵니다.**
> 기준일: 2026-07-31 · 수치는 개발 DB 실측값

---

## 1. 한눈에

| 데이터 | 보유량 | 커버리지 | 비고 |
|---|---:|---|---|
| 시군구(지역) | 250 | **100%** | 전국 |
| 관광지 | 6,769 | 250/250 지역 | |
| └ 대표 이미지 | 6,365 | **94%** | 404곳은 이미지 없음 |
| └ 상세 설명 | 31 | **0.5%** | 조회할 때마다 늘어남 (아래 §3) |
| 음식점 | 8,540 | 250/250 지역 | |
| 착한가격업소 | 12,106 | | 식당 외 업종 섞임 (아래 §4) |
| 특산물 | 62 | **24/250 지역 (10%)** | 대부분 지역에 없음 |
| 여행코스 | 347 | | |
| └ 경유지 보유 | 163 | **27/347 코스 (8%)** | 나머지는 API에 경유지 없음 |

---

## 2. 지역 소개글은 **없습니다**

TourAPI(KorService2)에 지역 단위 소개 문구를 주는 오퍼레이션이 없습니다.
`areaCode2` 응답 필드는 `rnum, code, name` 뿐이고, 나머지 오퍼레이션은 전부
개별 콘텐츠 또는 코드 단위입니다.

**디자인 함의**
- "안동은 정신문화의 수도로…" 같은 **서사형 문단을 큰 자리로 잡으면 채울 수 없습니다.**
- 현재는 가진 데이터로 문장을 구성합니다:
  > 경상북도 안동시에는 관광지 69곳, 음식점 20곳, 착한가격업소 44곳이 등록되어 있습니다.
  > 유교랜드, 안동민속촌, 안동댐 같은 곳을 둘러볼 수 있어요.
- 서사가 꼭 필요하면 **사람이 직접 쓰거나(운영 비용), AI 생성(사실 왜곡 위험)** 중 선택해야 합니다.

---

## 3. 관광지 상세 설명은 **나중에 도착합니다**

관광지 소개글(`overview`)은 콘텐츠 1건당 API 호출 2회가 듭니다.
6,769건을 전부 채우면 13,000회가 넘고 **1일 한도가 1,000회**라 2주가 걸립니다.

그래서 **사용자가 펼쳐 본 관광지만** 가져와 DB에 저장합니다(현재 31건).
한 번 가져오면 영구 보존되어 두 번째부터는 즉시 표시됩니다.

**디자인 함의**
- 카드/목록에 **설명이 처음부터 채워진 상태를 전제로 하면 안 됩니다.**
- "자세히" 같은 **명시적 펼치기 동작**이 필요하고, 그 사이 **로딩 상태**가 있어야 합니다.
- 한도 소진 시에는 설명 없이 이름·주소·사진만 나옵니다. 이 상태도 디자인이 필요합니다.

---

## 4. 착한가격업소에는 식당이 아닌 곳이 섞여 있습니다

미용실·세탁소·목욕탕·자동차정비 등이 포함되어 있습니다.
현재는 키워드로 걸러 **먹거리 자리에는 식당만** 노출합니다.

**디자인 함의**
- "이 지역 착한가격업소 N곳" 같은 **총계 숫자와 실제 노출 개수가 다릅니다.**
- 안동 예: 총 44곳이지만 식당만 추리면 그보다 적습니다.

---

## 5. 사용자 생성 데이터는 **아직 비어 있습니다**

| 데이터 | 현재 |
|---|---:|
| 가입 사용자 | 데모 계정 위주 |
| 저장된 코스 | 소량 |
| 후기 | **1건** |

**디자인 함의 — 가장 중요합니다**
- `/reviews`(후기 둘러보기)는 **빈 상태가 사실상 기본 화면**입니다.
  후기 카드가 가득 찬 그리드만 디자인하면 실제로는 그 화면을 볼 일이 없습니다.
- `/my/courses`도 신규 사용자에겐 항상 빈 상태로 시작합니다.
- **빈 상태를 "예외"가 아니라 "첫인상"으로 다뤄주세요.**

---

## 6. 좌표

| 항목 | 좌표 |
|---|---|
| 관광지 · 음식점 · 착한가격업소 | **있음** |
| 특산물 | 없음 (장소가 아님) |
| 여행코스 경유지 | 관광지와 매칭될 때만 |

**디자인 함의**: 코스에 특산물을 담으면 목록에는 남지만 **지도에는 찍히지 않습니다.**

---

## 7. 외부 API 한도

| API | 한도 | 쓰는 곳 |
|---|---|---|
| TourAPI | **1,000회/일** (950으로 가드) | 관광지 적재, 상세 조회 |
| 카카오맵 JS | 넉넉 | 지도 표시 |
| 카카오모빌리티 길찾기 | 300회/일(가드) | 코스 경로·거리·시간 |
| Gemini | 무료 등급 분당 제한 | AI 상담 |

**디자인 함의**
- 화면을 열 때마다 외부 호출이 필요한 디자인은 한도를 태웁니다.
- 코스 경로는 **저장 시점에 1회만** 계산하고 저장합니다 →
  **편집 중에는 소요시간·거리를 표시할 수 없습니다**(직선 동선만).

---

## 8. 늘릴 수 있는 것 / 없는 것

| | 방법 | 비용 |
|---|---|---|
| ✅ 관광지 상세 설명 | 조회 시 자동 축적 or 선적재 배치 | API 호출 |
| ✅ 여행코스 경유지 | 이미 전량 시도함 — API에 없는 게 대부분 | 복구 불가 |
| ✅ 특산물 | 직접 시드 데이터 작성 | 사람 손 |
| ❌ 지역 소개글 | API에 없음 | 직접 작성 또는 AI |
| ❌ 관광지 평점·리뷰수 | TourAPI 미제공 | — |
| ❌ 혼잡도·인기도 | 미보유 | 한국관광 데이터랩 별도 연동 필요 |

> **"인기 순 정렬", "평점 4.5 이상" 같은 UI는 현재 데이터로 만들 수 없습니다.**
> 서비스가 의도적으로 랭킹을 두지 않는 이유이기도 합니다(PRD 3-2 참고).
